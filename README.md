## 💡 O que é

<p align="justify">
<b>Daily Bee</b> é um aplicativo de produtividade e gerenciamento de tarefas que combina um design leve e descontraído para ajudar você a manter o foco e organizar sua rotina de forma prática.

O aplicativo é dividido em quatro abas principais:

- <b>Dia: </b> Seu dia divido em horas + suas tarefas diárias;
- <b>Tarefas: </b> Gerenciamento de suas atividades;
- <b>Home: </b> Visão geral do seu progresso;
- <b>Pomodoro: </b> Gestão do tempo e na manutenção da concentração.

## 🧱 Estrutura do projeto

```text
├─ backend/              # API e regras de negócio
│   └─ src/
│       ├─ database/     # Conexão e configuração do banco de dados
│       └─ modules/      # Módulos do sistema e suas regras de negócio
├─ database/             # Scripts, migrations e seeds do banco de dados
├─ docs/                 # Documentação e decisões do projeto
├─ frontend/             # Interface da aplicação
│   ├─ public/           # Arquivos públicos e estáticos
│   └─ src/
│       ├─ assets/       # Imagens, fontes e outros recursos
│       ├─ components/   # Componentes reutilizáveis
│       ├─ features/     # Funcionalidades organizadas por domínio
│       └─ themes/       # Temas, estilos e configurações visuais
└─ README.md             # Documentação principal do projeto
```
